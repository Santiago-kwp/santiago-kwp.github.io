### 학습 목표 : 컴퓨터 구조 개략적 이해 및 컴퓨터가 처리하는 데이터의 이해

### Chapter1 학습 내용 요약
- 컴퓨터 구조를 알아야 하는 이유 : 개발에 문제가 생겼을 때 문제 해결의 실마리가 될 수 있으며, 더이상 미지의 대상이 아닌 분석의 대상이 됨. => 다양한 문제를 스스로 해결할 수 있는 개발자가 될 수 있음
  - 이제는 프로그램을 성능, 비용, 용량 세 가지 면을 고려하여 프로그래밍해야 됨
- 컴퓨터를 한마디로 정의한다면? "명령어를 처리하는 기계"
- 컴퓨터 구조 
  - 메인보드
    - 버스라는 통로를 통해 연결된 부품들이 정보를 주고 받음
  - 시스템 버스
    - 네 가지 핵심부품(CPU, 메모리, 보조기억장치, 입출력장치)을 연결하는 버스
    - 주소 버스, 데이터 버스, 제어 버스로 나뉨
  - CPU
    - ALU(산술논리연산장치, Arithmetic Logic Unit) : 연산 담당
    - 레지스터 : 데이터 임시 저장
    - 제어장치(Control Unit) : 제어신호라는 전기신호를 내보내고 명령어를 해석하는 장치 (ex. 메모리 읽기, 메모리 쓰기)
  - 메모리
  - 보조기억장치
  - 입출력 장치

### Chapter 2 학습 내용 요약
- 정보단위 워드 : CPU가 한번에 처리할 수 있는 데이터 크기를 의미함.
  - x86 CPU는 32비트 워드 CPU
  - x64 CPU는 64비트 워드 CPU
- 2의 보수의 사전적 의미는 어떤 수를 그보다 큰 2^n 에서 뺀 값
  - 실제로는 0과 1을 반전 한다음 1을 더하면 됨
  - n 비트로는 -2^n 과 2^n 을 표현할 수 없는 한계가 있음
- 문자 인코딩 : 아스키 코드 - 영어와 아라비아 숫자 및 일부 특수문자 표현
  - 8비트로 표현하므로 128개이나 1개의 패리티 비트를 제외하고 127개의 문자를 표현할 수 있음!
- EUC-KR : 완성형 인코딩과 조합형 인코딩으로 구분되며, EUC-KR은 완성형 인코딩 방식으로 한글 단어에 2바이트 크기의 코드를 부여한다.
  - 완성형 인코딩은 가 : 1, 나 : 2 이런식으로 완성된 하나의 글자(초성,중성 종성의 조합)에 고유한 코드 부여
  - 조합형 인코딩은 초성을 위한 비트열, 중성을 위한 비트열, 종성을 위한 비트열이 있고 그것들의 조합으로 하나의 글자 코드를 완성하는 인코딩
  - 2,350 개 정도의 한글 단어를 표현할 수 있으나 부족해서 마이크로소프트의 CP949라는 EUC-KR의 확장된 버전이 있음.
