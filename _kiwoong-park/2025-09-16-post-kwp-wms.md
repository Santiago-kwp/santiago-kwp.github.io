### 순 공부 시간 : 25.9.16.22:40 ~ 9.17.00:05 (85분)

### WMS를 왜 만드는가?

- WMS의 목적 : 재고 및 창고 관리의 효율성 및 정확성 향상 => 창고 작업 효율성을 모니터링하고 개선
  - 재고 관리 및 추적 : 재고별 수량에 대한 관리 및 재고별 위치에 대한 추적
  - 주문 처리, 피킹 및 패킹 : 다양한 피킹 전략(건수별, 품목별 등) 및 효율적인 패킹 고려한 물류 워크플로우 최적화
  - 레이아웃 및 공간 최적화 : 재고 수준, 상품의 크기 및 회전율에 따라 제품의 최적 위치를 식별 및 할당 (회전율이 빠를수록 가까이, 상품의 크기가 크거나 회전율이 낮으면 뒤편에)
- WMS의 중요성
  - 창고 내의 활동을 관리하고 최적화
  - 재고 수준, 위치, 입고, 출하, 피킹, 패킹 등의 작업 관리
  - 자동화된 장비와 통합하여 창고 내에서의 물류 흐름을 관리, 효율화

WMS의 주요 지표(KPIs)

1. 입고 정확도
2. 적치 정확도
3. 출고 정확도
4. 주문 처리 시간
5. 재고 정확도
6. 공간 활용률
7. 노동 생산성
8. 주문 수행 시간
9. 출하 완료율
10. 출하 정확도

### 풀필먼트란?

> **고객의 주문 접수부터 고객에게 물품을 배송하는 것까지의 전 과정을 이행/완수하는 것
→ 온라인 판매자가 제품의 보관, 주문 처리, 배송과 관련된 작업을 위탁하고 판매자는 핵심 비지니스에 집중하도록 돕기 위한 서비스**
>
- 풀필먼트 서비스는 판매자와 구매자 간의 거래 과정에 초점을 둔다.
- 주요 비지니스에는 창고/재고 관리, 운송/배송, 자동화/설비

### 풀필먼트의 목표

- **신속, 정확한 처리**
- **신속, 정확한 정보 제공 (즉, 빠른 응답시간과 정확한 정보 관리)**
- **안정적인 운영 (고가용성 ~ 끊김이 없고, 중단X, 백업 및 위기 관리)**
- **효율적인 비용**

### 창고 관리 시스템에서의 DC와 TC

**DC : Distributed Center (보관형 물류센터)**

- **상품 보관, 재고 관리, 소매점으로 상품 공급**
- **특징 : 재고를 상당량 보유하고 관리하므로, 상품의 입고, 보관, 피킹, 출고 등 다양한 물류 활동이 발생**
- **주요 대상 : 일반적인 소매 상품 처럼 장기간 보관해야 하는 상품에 적합**

**TC : Transfer Center (통과형 물류센터)**

- **상품을 장기간 보관하지 않고, 입고된 상품을 즉시 분류하여 다른 목적지로 빠르게 이동시키는 데 집중**
- **특징 : 재고를 거의 보유하지 않으며, 상품 이동 효율성을 극대화하는 데 초점을 맞춤**
- **주요 대상 : 유통기한이 짧거나, 신선도가 중요한 식품(우유, 빵, 채소)처럼 당일 생산, 24시간 내 출고되어야 하는 상품에 적합**

### 재고란?

재고(Inventory or Stock)

- 정상(good) 재고와 불량(defective) 재고
- 안전 재고(safety stock) : 수요증가나 공급 지연에 대비하기 위해 보유하는 여분의 재고. 즉 버퍼 혹은 비상금의 개념
- 재고 실사 (Inventory count) : 실제 수량을 확인해서 시스템에 반영 => 즉 insert data into table or update table set column = data where ~~
- 로케이션 (Location) : 재고의 위치 정보
- SKU (Stock Keeping Unit) : 물류에서 물품을 식별하는 최소 단위
- LOT : 구분하거나 구별하기 위한 속성 정보
- 적치 (Putaway) : 물류센터에서 물건을 적당한 위치(로케이션)에 보관하는 작업
- 드랍시핑(Dropshipping) : 판매자가 재고를 보유하지 않고(즉, 별도 물류창고에 보관하지 않고) 도매상 또는 유통사를 통해서 바로 고객에게 배송시키는 유통방식

### 입고란?

입고 (Receiving or Inbound)

- 발주 입고 : 구매에 의한 입고, 발주한 결과에 의한 물품의 입고로 말 그대로 물품을 주문해서(발주) 창고로 들어옴
- 입고 지시 : 입고 작업을 지시하는 문서
- 반품 입고 (Return receiving) : 고객으로부터 반환된 상품이 센터로 입고
- 사전 선적 통지 (Advance Shipping Notice) : 어떤 상품이 언제 도착할지에 대한 정보로 언제쯤 재고가 확보되겠다고 예측할 수 있는 정보
- 입고 할당 (Inbound Allocation) : 입고될 물품이 저장될 위치를 사전에 결정하는 작업
- 입고 검수 (Receiving Inspection) : 입고된 상품의 품질이나 수량을 확인하는 작업
- 청구서 (Invoice) : 매매 거래를 정당하게 이행하였음을 밝히는 서류

### 출고란?

출고 (Outbound)

- 상품이나 물품이 창고나 센터에서 나가는 것
- 주문/판매 출고 : 고객의 주문을 받은 결과로 물품의 출고, 판매에 의한 출고로 소비자와의 거래가 일어남
- 출고 지시 (Outbound Order) : 출고 작업을 위한 지시
- 출고 할당 (Outbound Allocation) : 출고 지시건을 처리하기 위한 상품을 사전에 결정하는 작업. 즉, 보관된 물품 중 어떤 물품을 뺄 것인가를 결정
- 상차 : 출고 준비를 마친 출고건을 선적/상차 위치에 이동하여 운송업체에 전달
- 크로스 도킹 (전환 출고, Cross-Docking) : 물류센터에서 입고된 상품을 재고 보관 프로세스없이 임시 보관했다가 바로 출하하는 방식 ~ 캐싱

### 피킹부터 패킹까지의 주요 과정

- 피킹 : 작업자 혹은 자동화된 시스템(agv)이 피킹 목록에 따라 상품을 창고에서 꺼내오는 작업
  - 총량 피킹 : 여러 주문에 동일한 상품이 있을 때 상품별 총량을 한 번에 피킹
  - 주문 피킹 : 개별 주문서를 바탕으로 주문 건별 피킹 (한 장바구니에)
- 분배 : 각 상품을 주문 별로 분배/분류하는 작업
- 검수 : 선택된 상품을 검사하여 주문 내용과 일치하는지 확인하는 작업
- 패킹 : 상품을 배송할 수 있게 포장하는 작업
- 송장 라벨링 : 포장 단위에 송장 라벨을 붙이는 작업
