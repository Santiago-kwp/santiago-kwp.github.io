### Join의 이해

- 조인 연산이란 두 개의 테이블을 하나로 병합하는 연산이다.
- EQUI Join : 등식을 조건으로 사용할 때 발생하는 조인이다.
  - 컬럽 값이 정확하게 일치할 때 성립하는 것으로 where 절의 조건이 등식인 경우 발생
- Non EQUI Join : Where 절의 조건이 등식이 아닌 부등식(Between, <, >, ≤, ≥)을 사용해 범위를 나타내는 조건일 때 발생하는 조인

### Inner Join (내부 조인)

- 동등 조인이라고도 한다. 교집합의 개념인 듯하다.
- 한 테이블의 외래키로 다른 테이블의 기본키가 등록되어 있는 경우에 쓸 수 있다?
- 아래와 같이 같은 결과를 반환하는 내부 조인이 있을 수 있다.

```sql
select * 
from student s inner join lecture l on s.lecture_id = l.id

-- inner를 안붙여도 되는 것 같다.
select * 
from student s join lecture l on s.lecture_id = l.id

-- cross join 후 where 연산을 적용하는 방법도 있지만 gemini 한테 물어보니 잘 안쓰는 것 같다.
select *
from student s, lecture l
where s.lecture_id = l.id;
```

### 외부 조인(Outer join)

- 합집합의 개념인 듯하다.
- 기준에 되는 키에 따른 컬럼 값이 존재하지 않더라도, 모든 튜플(행)을 병합한다.
- 조인할 값이 한 테이블에는 존재하지만, 다른 테이블에는 없는 경우 NULL로 생성한다.

- Left Outer Join 과 Right Outer Join이 존재하는데, 머가 왼쪽이고 머가 오른쪽이지?
  - 아래 sql문을 직관적으로 봤을 때 왼쪽에 작성된 actor가 왼쪽이고, appearence 가 오른쪽이다
  - 왼쪽의 모든 행을 포함시키는 조인이 Left Outer Join

    ```sql
    Select *
    from actor a1 left outer join appearence a2 on a1.actor_id = a2.actor_id; 
    ```

- 왼쪽과 오른쪽 모두 포함시키는 게 Full Outer Join

### self join

- 별도의 연산 명령어는 없는 듯하다.
- 아래의 예시와 같이 한 테이블 내의 같은 데이터를 가지고 있는 행을 통해 (예시에서는 id 와 classes_id) 내부 조인이나 외부 조인 연산을 수행하여 셀프 조인을 한다.

```sql
-- 부족원의 직속상사 정보를 출력
-- (내부 조인을 사용한 셀프 조인)
select 
	ut_a.id as 부하ID, 
	ut_a.name as 부하, 
	ut_b.id as 직속상사ID, 
	ut_b.name as 직속상사
from ugaga_tribes ut_a 
	join ugaga_tribes ut_b on ut_a.classes_id = ut_b.id;

-- 직속상사가 없는 부족원의 정보까지 모두 출력
-- (외부 조인을 사용한 셀프 조인)
select 
	ut_a.id as 부하ID, 
	ut_a.name as 부하, 
	ut_b.id as 직속상사ID, 
	ut_b.name as 직속상사
from ugaga_tribes ut_a 
	left join ugaga_tribes ut_b on ut_a.classes_id = ut_b.id;테이블에서의 집합연산
```

### 서브 쿼리

- 쿼리를 수행한 결과를 또 하나의 테이블로 취급하여 그 테이블을 대상으로 또 쿼리를 수행하는 것을 서브 쿼리라고 하는 것 같다.
