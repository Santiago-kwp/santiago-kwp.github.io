## 1. 프로세스 동기화 관련 개념/용어 정리

### 프로세스 동기화(Process Synchronization)

- 시스템 내부에 여러 프로세스들이 존재할 때, 각 프로세스마다 다른 프로세스들에 관한 정보를 공유하면서 공유 데이터를 이용하는 시점을 조율하는 것

### 비동기적 프로세스(Asynchronous Process)

- 다른 프로세스에 관한 정보를 알지 못한 채로 작업을 독립적으로 수행하는 프로세스들을 의미

### 병행/병렬 프로세스(Concurrent Process)

- 여러 개의 프로세스들이 동시에 시스템에 존재하는 것을 의미

## 2. 상호 배제 관련 개념/용어 정리

### 공유 데이터(Shared Data/Critical Data)

- 여러 프로세스들이 공유하는 데이터

### 임계 영역(Critical Section)

- 공유 데이터에 접근하는 코드 영역(code segment)
- 작성한 코드 중에서 공유 데이터를 사용하여 어떤 작업을 수행하게 되는 범위를 의미

### 경쟁 상태(Race Condition)

- 병렬적으로 수행 중인 비동기적 프로세스들이 동시에 공유 자원을 이용할 때, 실행 순서에 따라 결과값이 달라지는 문제
- 경쟁 상태의 발생 원인
    - **시스템에서는 1개의 기계어 명령어가 실행되는 동안에만 다른 프로세스의 인터럽트가 없음**을 보장
    - 개발자가 작성한 1줄의 코드는 여러 개의 기계어 명령어로 구성될 수 있음
    - 1줄의 코드를 구성하는 **기계어 명령어들을 차례대로 1개씩 실행하는 도중, 공유 자원을 이용하는 다른 프로세스의 기계어 명령어들이 중간에 실행될 수 있음**
    - 별도의 조치가 없다면, **기계어 명령어 단위에서는 개발자의 의도와는 다른 순서대로 공유 자원에 접근할 수도 있음**

### 상호 배제(Mutual Exclusion)

**개요**

- 상호 배제란 2개 이상의 프로세스가 동시에 임계 영역에 접근하는 것을 방지하는 것을 의미
- 상호 배제의 목적은 Race Condition의 방지를 통해 프로세스 동기화를 수행함으로써, 개발자의 의도대로 프로그램이 실행되는 것을 보장하는 것

**상호 배제의 기본 연산**

- enterCS()
    - 한 프로세스가 임계 영역에 진입하기 전, 임계 영역을 이용하는 다른 프로세스가 있는지를 검사하는 연산에 해당
    - 임계 영역에 진입한 프로세스가 없다면, 현재 프로세스는 임계 영역에 진입
- exitCS()
    - 프로세스가 임계 영역을 벗어날 때, 시스템에게 현재 프로세스가 임계 영역을 벗어났음을 통지하는 연산에 해당

**상호 배제의 성립 조건**

※ 아래의 3가지 요건들을 모두 충족해야 함

- **상호배제(Mutual Exclusion)**
    - 이미 임계 영역에 진입한 프로세스가 있을 경우, 다른 프로세스의 진입을 금지해야 함
- **진행(Process)**
    - 임계 영역에 진입한 프로세스가 없을 경우, 다른 프로세스가 임계 영역에 진입하는 것을 방해하지 않아야 함
- **한정 대기(Bounded Waiting)**
    - 임계 영역을 이용하는 프로세스라면, 어느 시점부터는 반드시 임계 영역에 진입할 수 있어야 함
    - 즉, 프로세스가 임계영역에 진입하지 못한 채 무한정 대기하게 되는 것을 방지해야 한다는 것을 의미
