## SQL

## SQL의 개념

데이터베이스를 관리할 때 사용하는 언어로 **데이터를 만들고(DDL), 넣고/고치고(DML), 꺼내보고(DQL), 접근 권한 관리(DCL)** 하는 데 필요한 **표준 언어이다**.

## SELECT 문

### 1.SELECT 문의 구성 요소
  - select → 어떤 것을 출력할지 (속성 이름)
  - from → 어떤 테이블에서 가져올지 (테이블 이름)
  - where → 어떤 조건을 걸쳐갈지 (검색 조건)
  - group by → 어떤 값들을 그룹으로 묶을지 (속성 이름)
  - having → 또 하나의 어떤 조건을 걸쳐갈지 (검색 조건)
  - order by → 어떻게 정렬할지 (ASC | DESC)

### 2.연산자
  1. 비교: =, <>, <, <=, >, >=
  2. 범위: BETWEEN → ex) BETWEEM 100 AND 200
  3. 집합: IN, NOT IN → ex) IN(100, 200)
  4. 패턴: LIKE
     - LIKE ‘HAWON’
     - LIKE ‘%A%’ (‘A’가 포함된)
     - LIKE ‘A%’ (앞글자가 ‘A’인)
     - LIKE ‘%A’ (뒷글자가 ‘A’인)
     - LIKE ‘_A%’ (두번쨰 글자가 ‘A’인)
  5. NULL: IS NULL, IS NOT NULL
  6. 복합조건: AND, OR, NOT

### 3.집계함수
  - SUM: 합계
  - AVG: 평균
  - COUNT: 카운트 수
  - MAX: 최대값
  - MIN: 최저값

### 4.ORDER BY 절 정렬
  - ASC: 오름차순
  - DESC: 내림차순

### 5.기타 명령어
  - DISTINCT: 중복 제거
  - STR_TO_DATE: 날짜 포맷 규격 지정 → ex) STR_TO_DATE(’2000_12_06’,’%Y_%m_%d’)
  - CONCAT: 함께 출력 → ex) CONCAT(FIRST_NAME(고), LAST_NAME(하원)) ⇒ 고하원
  - AS: 출력 카테고리 이름 지정 → ex) LAST_NAME AS 이름 ⇒ 이름 | 하원
