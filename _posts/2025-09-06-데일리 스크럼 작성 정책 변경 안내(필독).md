## ✍️데일리 스크럼 작성 정책 변경내용

### 변경 사항
- (기존) `_dailyScrumProject` 폴더에 `*.md` 파일을 업로드하는 방식
- (변경) `_팀원이름영문` 폴더(최신 `gh-pages` 브랜치에서 이미 만들어 놓음)에 `*.md` 파일을 업로드하는 방식
  - 새폴더명 : `_hawon-ko, _jaeyun-kim, _kiwoong-park, _hyeonbin-lee, _gun-sin`
- (변경) 기존의 `_dailyScrumProject` 폴더에는 팀원과 공유하고 싶은 내용의 포스팅 작성, 자신의 데일리 스크럼을 팀원과 공유하고 싶다면 중복하여 두 폴더에 업로드

> 우선 개인단위로 스크럼 내용을 확인할 수 있도록 팀원의 이름으로 된 탭을 신설하였습니다.
> 예를 들어, 자신이 쓴 글을 따로 복사해서 가져간다던지, 예전에 쓰던 글의 내용을 재사용하고 싶은데 현재는 다 합쳐져 있어서 찾기가 귀찮은 상황을 줄이기 위함입니다.
>
> 기존에 쓰던 전체 스크럼 게시판은 팀원 전체에 공유하고 싶은 공통 내용에 대한 포스팅으로 작성하시면 되며, 자신이 쓴 내용을 팀원과 공유도 하고 싶고, 내 데일리 스크럼으로 작성하고 싶다고 하면 양 폴더(`_dailyScrumProject` 및 `_자신의 이름 폴더`)에 중복하여 업로드 바랍니다.

### 변경 목적
> 변경 목적은 개인이 쓴 글을 조금 더 쉽게 관리할 수 있게하기 위함입니다. 현재 개인별로 포스팅 수의 편차가 있는 것은, 개인적으로 로컬에 공부하고 있는 내용이 따로 있기도 하고 추가로 올리는 게 번거롭고, 귀찮아서라고 생각하고 있습니다.
> 
> 물론 개인의 상황과 이해는 100%는 공감하지만, 저는 자신이 공부한 내용을 팀 게시판을 통해서 한 번이라도 머릿속에서 꺼내보는 것이 개인적 측면으로는 장기 기억에 매우 큰 도움이 됩니다.(열심히 공부한 내용을 며칠만에 잊어버리고 싶은 사람은 없습니다.) 
> 단기적으로는 익숙하지 않고, 별것 아닌 공부 내용을 포스팅하는 것이라서 들이는 시간에 비해 효용이 없다고 생각할 수도 있지만, 장기적으로 봤을 때 공들여 포스팅을 해보면 기억에 훨씬 오래남고(미신이 아닌 science) 정리한 내용을 추후 쉽게 재사용할 수 있습니다.
> 
> 또한, 팀적으로도 서로 열심히 공부하고 있는 상황 자체를 공유하고, 어떤 내용을 보완 혹은 강화해서 공부하는지 공유할 수 있기 때문에 내가 안올리면 나만 손해지라는 생각보다는 내가 포스팅을 올림으로써 나한테도 도움이 되고 팀의 전체 퍼포먼스에도 도움이 된다고 생각해주시면 감사하겠습니다. (응집력 있는 팀 전체의 성과는 항상 개인 여럿이 독립적으로 낸 성과와 비교할 수 없습니다.)

## 🔄Git 워크플로우 ([맨 위로 이동](#))

### 1. 작업 전 최신의 메인 브랜치 상태로 로컬 컴퓨터에 업데이트
```bash
# git checkout 과 switch는 기능 동일함
git switch gh-pages
git pull
```

### 1-1. 만약 로컬의 작업 상황이 있어서 `pull` 이 안되다면
```bash
git switch 내브랜치명
git stash
git switch gh-pages
git pull
```

### 2. 내 브랜치를 최신화 하기
```bash
git switch 내브랜치명
git merge gh-pages
# 로컬에 작업 상황이 있었던 경우는
git stash pop
```

### 3. 파일 추가 및 커밋
```bash
# 변경사항 확인
git status

# 파일 추가
git add _자신의폴더명/*.md
# 또는 모든 변경사항 추가
git add .

# 커밋
git commit -m "Add: 새 포스트 - 포스트 제목"
```

### 4. 원격 저장소에 푸시
```bash
# 새 브랜치인 경우
git push -u origin 내브랜치명
# 이후 푸시
git push
```

### 5. Pull Request 생성
1. GitHub 저장소 페이지 방문
2. "Compare & pull request" 클릭
3. 제목과 설명 작성
4. "Create pull request" 클릭
5. 팀원 리뷰 후 merge (**슬렉에 스크럼 올렸다고 알려주세요!**)
