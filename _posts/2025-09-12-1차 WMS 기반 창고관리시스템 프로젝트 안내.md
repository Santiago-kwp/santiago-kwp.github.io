### 📈1차 프로젝트 진행 흐름

1. 프로젝트 주제 선정
2. 프로젝트 요구사항 분석 및 필수 기능 추출 (개념적)
3. 프로젝트 데이터베이스 모델링(ERD), 클래스 및 인터페이스 설계 ( 메인 Git branch 생성)
    1. 테이블 간 관계 (1:1, 1:N, N:M 등) 정의
    2. 필수 변수 및 메소드 정의
4. 팀원별 구현 담당 지정 및 구현 시작 ( Git branch 분화 작업)
    1. 각자 구현 기능 테스트
5. 팀원 작업 종합 ( Git pull request and merge)
6. 4 - 5 번 반복하며 요구사항 충족 확인 및 SW 완성
7. 프로젝트 랩업, 배운 내용 및 아쉬운 점, 추가 더 구현할 내용 정리 (README.md) 작성



### 📌‘25. 9.15.(월) 까지 팀원별 해야 하는 업무 안내

- 프로젝트 주제(도메인) 의견 제시 : 어떤 제품을 창고에 넣을 것인지 개인의 의견 제시 및 근거를 정하여 다음주 월요일 팀 회의에 의견 피력 ⇒ PPT나 PDF로 정리해서 파일로 가져오세요!
    - 관련 추가 설명 : 1차 프로젝트는 창고 입출고 관리시스템으로 우리의 클라이언트는 일반 소비자가 아니라 창고 관리가 필요한 **“쇼핑몰 사장님”**임. 즉, 어떤 제품을 판매하는 사장님을 우리 소프트웨어 클라이언트로 할 것 인지를 선정해야 한다.
    - 예를 들어, 냉동식품, 의약품, 의류, 기자재, 가구, 도서, 전자제품, IoT제품 등 자신에게 친숙한 제품이거나 혹은 시장의 요구사항이 뚜렷하거나, 시장 규모가 크거나, 몇몇 업체가 독과점인 시장이거나, 유통 구조가 단순 혹은 고정되어 있거나 등
    - 자신의 의견만을 제시하는 것이 아니라 의견을 뒷받침할 수 있는 근거가 제시되면 자신의 아이디어가 선택될 수 있는 확률이 높아지겠죠?
    - 최종 주제 선정은 주제 이해 접근성, 시장성(시장 규모, 성장성), 구현 난이도의 적절성을 기준으로 의견을 수렴해서 정할 예정입니다
- **프로그래머스 SQL Kit LEVEL1, LEVE2 모든 문제 풀이 : 풀어서 공용 깃헙에 업로드 및 자신이 재사용할 수 있도록 분류하세요.**  (Ex. only select, select with join, select with subquery, select with 집계함수, select with 순위함수 등등)
