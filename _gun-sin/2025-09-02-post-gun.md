# 구상

## 1. Student.java(모델의 객체)

학생 1명의 성적 정보를 표현하는 직렬화 가능한 도메인 클래스를 만들라고 하였으니 implements Serializable을 클래스명 옆에 붙혀준다.

요 것이 직렬화다. 직렬화를 예시를 들어보겠다. 사람은 컴퓨터한테 전원을 꺼달라고 요청하고 싶다. 이 말을 컴퓨터는 사람의 말로 표현을 하면 못알아먹는다. 그래서 사람의 말을 byte단위로 쪼개서 이진법으로 말을 하면 알아 먹는다.

즉 사람의 말을 byte 단위로 쪼개서 기억해 놓는 것을 직렬화

반대로 컴퓨터가 저장해놓은 byte 단위의 정보를 사람의 말로 다시 되돌려 놓는 것을 역직렬화라고 한다.

```java
**필드/속성**

- `name:String`
- `record:List<Integer>` (과목 점수: Integer )
- `total:int`, `average:double`, `grade:String`
- `serialVersionUID = 1L`
```

요런 필드와 속성을 가진 클래스 라고 한다.

하나 하나씩 해보자

```java
public class Student implements Serializable//직렬화
private String name;// 이름 문자열
private int[] record;//과목이 국영수과 과목4개 점수도 4개 고로 배열
private int total// 총합 정수타입
private double average// 평균 소수
private String grade// 학점 문자열
static final long serialVersionUID =1;//직렬화 할때 버전 식별자

```

가장 까다로운 마지막 문장을 살펴보겠다.

| 구성요소 | 설명 |
| --- | --- |
| static | 클래스에 귀속됨(클래스 내에서만 쓰인다) |
| final | 값 변경 없음 |
| long | 문장타입 |
| serialVersionUID | 직렬화 버전 식별자 |
| =1 | 버전 번호를 1로 지정한다. |

*** 직렬화 버전 식별자: 인터페이스를 구현한 클래스가 직렬화된 객체와 호환되는지 확인하기 위한 고유번호이다. 개발자가 직접 지정하면 클래스 구조가 바뀌어도 호환성을 유지 할 수있다.

### 선언방법

```java
static final long 타입이어야 함

이름은 반드시 serialVersionUID

값은 1L, 100L, 20230902L 등 자유롭게 지정 가능
```

다음으로는 생성자를 만든다.

```java
public Student(){//클래스명과 같으므로 생성자라고 생각하였다.
this.name = "^^";//종료를 원하면 ^^이것을 입력
this.record = new int[4]// 국영수과 점수를 총 4개를 입력받기 위한 4칸짜리 배열
}
```

```java
public Student(String name,int []record){//생성자 오버로드
this.name =name;
this.record = record;
this.makeScores();//생성자 안에서 메서드 호출
}
```

밑의 것은 생성자 오버로드라는 것이다. 같은 클래스 안에 이름은 같지만 매개변수가 다른 생성자를 여러 개 정의 하는 것이다. 생성자 안에 이름이란 문자열도 넣고  점수란 정수타입도 넣을 수있게 생성자 오버로드 한것이다.

다음으로 는 배열을 정의 해야 한다.

```java
public Student(String name, int korean, int english, int math, int etc){
//생성자 안에는 이름과 record라는 배열이 있다. 배열에는 국영수과 점수를 넣는다.
 record = new int[4];//레코드는 4칸짜리 배열이다
  this.name = name;
this.record[0] = korean;// 첫번째 칸에는 국어점수
		this.record[1] = english;//두번째 칸에는 영어점수
		this.record[2] = math;//세번째 칸에는 수학점수
		this.record[3] = etc;//네번째 칸에는 과학점수

		this.makeScores();//4개의 총합과 평균을 구해주는 메서드 소환
}
```

Student 생성자 안에 있는  name이라는 문자열 값과 record라는 배열 안의 값을 넣어줬다.

그리고 배열에 들어있는 값의 총합과 평균을 구해주는 메서드를 소환하였다.

```java
	public int[] getRecord() { //get 구문 이거는 값을 꺼내는 메소드야
		return this.record;//리턴값으로 꺼낸 값을 저장한다.
	}
	
	public int getTotal() {
		return this.total;
	}
	
	public float getAverage() {
		return this.average;
	}
	
	public String getGrade() {
		return this.grade;
	}
```

private으로 선언된 필드는 외부에서 직접 접근 할 수 없기 때문에, 값을 읽기 위한 공개 메서드(public)을 따로 만들어야 한다. 또한 꺼낸 값을 저장하기 위해 리턴값을 지정해줬다.

```java
private void makeScores(){
for (int i = 0 ; i <4; i++)
//i는 칸이라고 생각 하면 된다. 0번부터 시작하고 4개의 칸이 준비 되어 있다. 1칸씩 증가
			this.total += this.record[i]; //총합에 해당칸의 점수를 더한다.
			this.average = (double) this.total/4; // 총합을 과목수로 나누면 평균
		this.makeGrade();//등급 맥이는 메서드 소환

}
```

총합과 평균을 구하는 메서드를 정의하였다.

```java
private void makeGrade() {
		if (90 <= this.average && this.average <= 100)
			this.grade = "A";
		
		else if ( 80 <= this.average && this.average < 90)
			this.grade = "B";
		
		else if ( 70 <= this.average && this.average < 80)
			this.grade = "C";
		
		else if ( 60 <= this.average && this.average < 70)
			this.grade = "D";
		
		else if ( 0 <= this.average && this.average < 60)
			this.grade = "F";
	}
```

점수를 학점을 바꿔주는 메서드 이다. 과목이 여러 개 이므로 반복문을 통해서 정의하였다.

```java
public String toString() {
//to 스트링을 쓰지 않으면 원하는 데이터값이 아닌 주소값으로 출력되어 하는 값을 출력받지 못한다.
		return record[0] + "\t " + record[1]+ "\t " + record[2] + "\t " + record[3] + "\t "+total+ "\t"+average+ "\t  "+grade;
	}

}
```
