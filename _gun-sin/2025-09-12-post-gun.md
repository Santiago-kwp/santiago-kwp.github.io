먼저 다오 클래스가 다소 코드가 길어서 기능 별로 단계 별로 진행하였다.

## 1. 글 등록기능

```java
 public boolean createBoard(Board board) {
        //1. Connection 필요
        conn = DBUtil.getConnection();
        //2. 쿼리 생성
        String sql = " insert into boardTable(btitle,bcontent,bwriter,bdate) values(?,?,?,now())";
        //3. Connection 쿼리를 담아 DB서버로 request 할 객체 PrepareStatement 생성
        try (PreparedStatement pstmt = conn.prepareStatement(sql, PreparedStatement.RETURN_GENERATED_KEYS)) {//pr키 받아오기
            //4. 값을 셋팅
            pstmt.setString(1, board.getBtitle());//vo는 저장소고 거기에 있는 데이터를 가져와서 첫번째 값으로 사용한다.
            pstmt.setString(2, board.getBcontent());
            pstmt.setString(3, board.getBwriter());
            //5. 서버로 전송 후 결과값 (int 성공 1 실패 0)
            int affected =  pstmt.executeUpdate();// 인설트문(sql)이 실행
            boolean ok = affected > 0; //ok true
            //생성된 PK를 Board 객체에 반영 자동으로 만들어놓은 프라이머리키를 가져온다.
            try (ResultSet rs = pstmt.getGeneratedKeys()) { //GeneratedKeys 키값을 가져오는 역할
                if (rs.next()) {
                    int newbno = rs.getInt(1);
                    board.setBno(newbno);
                    boardList.add(board);
                }
            }
            return ok;

        } catch (SQLException e) {
            e.printStackTrace();
            return false;
        }
```

첫 번째로  구현할 기능은 글 등록 기능이다.

- int newbno를 보고 PR키가 bno구나를 알게 되었고 또한 칼럼에 추가해야 된다는 것을 생각했다.

```sql
use bookmarketdb;
delimiter $$
create procedure createBoard(
	in btitle char(20),
	in bcontent text,
	in bwriter char(30),
	out outvalue int)
```

이제 주요 부분을 보고 생각 했던 것들을 하나 하나씩 구현해보았다.  북마켓 DB를 연결 시켜 주었으며 오늘 배웠던 procedure을 이용하여 작성해보았다.

Procedure은 사용자가 반복되는 작업을 키워드로 정하여 키워드만을 호출하여 반복되는 기능을 수행 시켜주는 도구이다. 여기서 주의해야 할 점은 in, out이다.

- in 매개변수:

 btitle의 데이터를 booktmarketdb에서 받아와서 프로시저 내부에서 사용하는 것이다.

- out 매개변수:

프로시저 내부에서 값을 설정하면, 그 값이 호출한 쪽으로 반환하는 것이다.

- 참고로 bno는 자동으로 채워지므로 언급을 하지 않았다.
- bdate는 now타입을 생각하고 있어서 언급을 하지 않았다.

```sql
begin
	insert into boardtable( btitle,bcontent,bwriter,bdate)
    values(btitle, bcontent, bwriter,now());
	select max(bno) into outValue from boardtable;
end $$
delimiter ;    
```

- 프로시저의 시작과 끝이다. 각각의 칼럼들을 boardtable에 생성하였고 위에서 정한 타입들로 반환하게 타입들을 지정하였다.
- 또한 데이터를 입력받으면 bno를 기준으로 점차적으로 큰 숫자들을 부여하게 하였다.

## 2. 전체 글 조회 기능

```java
    String sql = "SELECT bno, btitle, bcontent, bwriter, bdate " +
                     "FROM boardTable" +
                    " ORDER BY bno DESC";
```

전체 글 조회는  boardtable을 bno, btitle, bcontent, bwriter, bdate의 칼럼을 가진다.

- order by bno desc를 보아 내림차순 정렬해야 한다고 생각했다.

```sql
delimiter $$
create procedure selectall()
begin
	select b.bno, b.btitle, b.bcontent, b.bwriter,b.bdate
    from boardtable b
    order by bno desc;
end $$
```

selectall()이라는 프로시저를 만들었으며 boardtable에서 각각의 칼럼들 조회하여

bno를 기준으로 내림차순으로 정렬하였다.
