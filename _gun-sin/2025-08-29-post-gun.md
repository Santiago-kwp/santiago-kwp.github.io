# ChatServerClass

## 1. 필드

먼저 우리는 실행 및 처리를 담당하는 클래스인 ChatServer  Class 부터 살펴보자. 그 전에 눈을 감고 한번 상상을 해보자. 아니 잠들지 말고 생각을 해야한다. 강사님은 9차수 수강생들에게 메세지를 보내고 싶어한다.
“선착순 3명 고기 사드립니다 ”이런 문구를 보내고 싶어한다. 그러면 강사님은 어찌 보내야 하나 슬랙을 키고 메세지를 입력하세요 칸에 메세지를 입력하고 전체발송버튼을 누르면 메세지가 보내진다. 이걸 항상 기억하고 있어야 한다. 

```java
  public class ChatServer {
  ServerSocket serverSocket; //클라이언트의 연결 요청 수락
  public ExecutorService threadPool = Executors.newFixedThreadPool(100);
	//100개의 클라이언트가 동시에 채팅할 수 있도록 준비
  Map<String, SocketClient> chatRoom = new ConcurrentHashMap<>(new Hash<>());)
  // 통신용 SocketClient를 관리하는 동기화된 Map 컬렉션
```

먼저 이번 클래스는 3개의 필드로 구성되어있다.

| 변수 이름 |  임무 |
| --- | --- |
| serverSocket | 클라이언트의 연결 요청을 승인한다. |
| threadPool | 최대 동시에 100개의 클라이언트를 연결 할 준비를 한다. |
| chatRoom | 동시에 처리요청이 들어오면 하나 씩 처리를 한다. 처리를 하는 도중 다른 것들은 처리하지 못하도록 멈춰 놓는다.(싱크로나이즈) |

자 이제 한 줄씩 정리해보겠다. 

```java
ServerSocket serverSocket; //클라이언트의 연결 요청 수락
```

서버는 큐 타입으로 처리를 한다. FIFO방식이다. 즉 선입 선출 먼저 요청이 들어오는 순서대로 처리해준다. 여기서 주의 해야 할 점은 하나 씩 만 처리를 한다는 것이다.  그리고 서버는 엄청 도도한 녀석이라 먼저 접근하지 않는다 오로지 요청이 있어야 처리를 하는 녀석이다.

```java
public ExecutorService threadPool = Executors.newFixedThreadPool(100);
```

우리는 1대1 채팅 프로그램을 만드는 것이 아니다. 다수의 클라이언트와 서버 1개로 이루어지는 채팅 프로그램을 만드는 것이다. 그래서 우리는 다수의 클라이언트를 받아드릴 준비를 해야 한다. 이번에는 100개의 클라이언트를 받을 마음의 준비를 하는 것이다. 101번째 클라이언트가 요청을 하면 다른 클라이언트가 나갈 때까지 대기를 명하는 것이다. 즉 채팅방이 하나 있다. 제한 인원은 100명만 들어 갈 수 있다. 101번째 사람이 오면 대기 시켰다가. TO가 생기면 들어오게 시키는 것이다.

```java
Map<String, SocketClient> chatRoom = new ConcurrentHashMap<>(new HashMap<>());)
```

Map방식으로 SocketClient에 있는 정보를 문자열 타입의 키와 세트로 저장 한다는 의미이다. 이게 뭔 소리냐면 Map은 키와 데이터를 세트로 묶어서 관리한다. 키가 입력되면 chatRoom이라는 변수에 데이터를 저장한다.

우리가 카톡을 실행시키기 위해서 아이콘을 누르는데 여기서 아이콘을 누르는 행위를 키, 카톡이 실행되는 행위를 데이터라고 생각 하면 된다.

## 2. 메서드

클래스를 만들고 필드를 만들었다. 이제 뭐를 만들어야겠는가? 이제 메서드를  만들어야 한다. 그러면 어떠한 메서드들이 필요하겠는가?

먼저 서버를 시작하는 메서드가 필요할 것이며 시작했으니 종료하는 메서드도 필요 할 것이다.

그리고 다중의 클라이언트 연결을 한다고 했으니 각각의 클라이언트들을 생성하고 가지고 있는 데이터들을 Map으로 넣는 메서드와 Map을 실행하고 종료하는 메서드도 필요하다.

일괄발송을 구현하고 하니  브로드캐스트 매서드도 넣어야 하며

마지막으로 이걸을 표현할 메인 메서드도 필요하다.

| 메서드 이름 | 하는 일 |
| --- | --- |
| start | 서버를 시작한다. |

## 2-1 start 메서드

서버를 사용 할려면 가장 먼저 무엇을 해야 하는가? 일단 켜야지 사용이 가능하다. 그래서 처음으로 start라는 메소드를 정의 할 것이다. 

```java
public void start() throws IOException{
	serverSocket = new serverSocket(50001);
	System.out.println("Server started");
	
	Thread thread = new Thread( 
	() -> {
		try {
                     while (true){
                    //람다식이 하는 일을 개발자가 아래와 같이 2가지를 지정함
  		        Socket socket = serverSocket.accept();//accpet()로 연결을 수락
			Socketclient client = new SocketClient(this, socket);
   		}
   
                      } catch (IOException e) {
                        e.printStackTrace();
                             } catch (Exception e) {
                          }
                        }
                     );
                        thread.start();
                    }
```

start라는 메서드를 인스턴스 메서드로 선언하였다. 서버클래스에서만 사용하면 되는 것이고 또한 객체 없이도 사용 가능하기 때문이다.(한 번 더 모르면 강사님한테 불려갈 수도) 앞에서 만든 클라이언트의 연결 요청을 수락하는 기능을 탑재 하고 있다. 수락을 위해서 Port 번호 50001를 가진 서버소켓을 생성하고 서버 시작을 알리는 문구를 출력하도록 작성하였다.

그 뿐만 아니라 행위 단위인 스레드를 통해서 ChatClient와 서버소켓의 Port  번호가 일치하면 accpet로 연결 하고 Client의 요청들을 서버소켓에 저장하도록 구현했다. 이를 새로운 클라이언트들이 생성될 때마다 실행 하도록 반복문을 사용했고 try-catch문으로 예외를 잡았다.

## 2-2 addSocketClient 메서드

지금 서버를 켰다. 다음으로 서버는 무슨 일을 해야겠는가? 클라이언트와 연결을 해야한다.

```java
  public void addSocketClient(SocketClient socketClient) {
        String key = socketClient.chatName + "@" + socketClient.clientIp; 
        chatRoom.put(key, socketClient);
        System.out.println("입장 > :" + key);
        System.out.println("현재 채팅자 수: " + chatRoom.size() + "\n");
    }
```

우리는 다중의 클라이언트들을 다뤄야 한다. 이들의 데이터들을 Map으로 관리한다고 했으니 문자열의 키값에  서버 안에 존재하는 소켓 Socket Client

(3일차때 다룰 것이다)에서 닉네임과 ip주소를 key에 저장한다.

그리고 채팅룸에 참여시킨다. 누가 입장했는지와 현재 채팅방 인원수를 

출력문을 추가하였다.

## 2-3 removeSocketClient 메서드

채팅방 입장을 만들었으니 당연히 퇴장도 만들어야 한다.

```java
    public void removeSocketClient(SocketClient socketClient) {
        String key = socketClient.chatName + "@" + socketClient.clientIp;
        chatRoom.remove(key);
        System.out.println("퇴장> :" + key);
        System.out.println("현재 채팅자 수: " + chatRoom.size() + "\n");
    }
```

add랑 비슷하므로 설명은 생략하겠다.

## 2-4 sendToAll

이제 채팅방에 인원들을 모으는 것까지 구현 해놨다. 이제 사람들을 모았으니 이제 말을 하면 된다. 전에 일괄 발송을 구현한다고 했으니 일괄발송 만 구현하겠다.

```java
  public void sendToAll(SocketClient sender, String message) {
        JSONObject root = new JSONObject();
        root.put("clientIp", sender.clientIp);
        root.put("chatName", sender.chatName);
        root.put("message", message);
        String json = root.toString();    

        Collection<SocketClient> clients = chatRoom.values();
        for (SocketClient client : clients) {
           if (client == sender) continue;
            client.send(json);
        }
    }

```

이 메서드는 보내는 사람과 입력한 메세지를 변수로 가지고 있으며 우리의 제이슨씨도 사용하고 있다. 제이슨은 쉽게 말하면 한 줄에 키와 데이터를 한줄에 출력하게 하는 텍스트 형식이다. 보내는 사람 담당 클라이언트의 ip 주소와 닉네임, 메세지를 한 줄로 출력 하기 위해서 데이터들을 제이슨에게 저장한다.그 다음에는 제이슨에 저장된 것을 채팅방에 ip 주소가 있는 사람들한테 메세지들을 보낸다. 하지만 본인한테는 본인이 쓸 필요 없으므로 for if문으로 제외시켰다.

## 2-5 stop 메서드

자 이제 일괄발송도 했다. 이제 서버는 본인이 할 꺼 다했다. 이제 그만 놓아주어야 한다.

```java
    public void stop() {
        try {
            serverSocket.close();
            threadPool.shutdown();
            chatRoom.clear();
            System.out.println("서버 종료");
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

```

서버를 종료하겠다고 팍 끄면 프로그램이 아작난다. 종료에는 절차라는게 있다. 식당이  장사 끝났다고 셧더 닫고 그냥 집가면 어후…. 그래서 종료 절차를 시작하게 할거다. 간단하다 켰더거 다끄면된다. 서버소켓 끄고 쓰레드 풀 끄고

채팅방을 비우고 사용자가 놀라지 않도록 서버 종료라고 알려주고  예외 잡고 끝이다.

## 2-6 Main 메서드

메인이다. q를 입력하면 서버를 종료하게 만들려고 한다.

사용자가 입력한 것을 한 줄씩 읽으면 되니 BufferdReader를 썻다.  

```java
    public static void main(String[] args) {
        try {
            ChatServer chatServer = new ChatServer();
            chatServer.start();

            System.out.println("----------------------------------------------------");
            System.out.println("서버를 종료하려면 q를 입력하고 Enter.");
            System.out.println("----------------------------------------------------");

            BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
            while (true) {
                String key = br.readLine();
                if (key.equals("q")) break;
            }
            br.close();
            chatServer.stop();
        } catch (IOException e) {
            System.out.println("[서버] " + e.getMessage());
        }
    }
}
```
