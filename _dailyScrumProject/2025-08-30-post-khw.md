## [Multi Echo Server] 코드 및 메소드 분석
### 순 공부 시간

8.30.18:00 ~ 17:30 (90분)

### 학습 내용 요약

- 서버와 클라이언트의 소켓을 통한 연결 방법과 채팅의 기능을 구현해봄.
- 기존 코드를 분석함으로써 효율적인 메소드와 새로운 구현 방법을 알게됨.

### 서버 클레스
1. 서버가 사용할 포트 번호와 클라이언트 요청을 처리할 스레드풀, 접속한 클라이언트마다 고유번호를 부여하기 위한 카운터를 선언해준다.
```c
    //서버가 사용할 포트 번호 선언
    private static final int PORT = 20000;
    
    //클라이언트가 접속하여 필요할 떄마다 새 스레드를 만들고, 재사용 가능한 스레드가 있을때 재사용해주는 메소드
    private static final ExecutorService POOL = Executors.newCachedThreadPool();
    
    //멀티스레드 환경에서 안전하게 증가하는 카운터로 클라이언트 고유 번호 발급용도로 쓰이는 메소드
    private static final AtomicInteger CLIENT_SEQ = new AtomicInteger(1);
```
2. 서버 시작 메세지 출력 후, JVM 종료 시 스레드풀을 정리하는 종료 훅을 등록한다. 이후 클라이언트의 접속을 대기하고, 연결이 수락될 때마다 고유 번호와 함께 ClientHandler 작업을 **스레드풀(POOL)**에 제출해 병렬 처리한다. 소켓/IO 예외는 로그로 남긴다.
```c
    public static void main(String[] args) {
        System.out.println("[서버] 시작 " + PORT ); //서버가 어떤 포트로 열렸는지 출력
        
        //JVM 종료 시 종료 메세지를 출력하고 모든 스레드풀을 종료시켜주는 기능
        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            System.out.println("\n[서버] 종료");
            POOL.shutdown();
        }));
        
        //서버 소켓 생성 후 클라이언트 접속 대기 후, 접속 시 승인하고 클라이언트에게 고유 번호를 부여하여 이를 스레드풀에 작업을 넘기는 기능
        try (ServerSocket serverSocket = new ServerSocket(PORT)) {
            while (true) {
                Socket socket = serverSocket.accept();
                int id = CLIENT_SEQ.getAndIncrement();
                POOL.submit(new ClientHandler(socket, id));
            }
        } catch (IOException e) {
            System.out.println("[서버] 에러: " + e.getMessage());
        }
    }
```
3. 데이터의 입출력을 어떻게 할지 설정해준다. 클라이언트가 접속하여 넘어왔기에 환영 메세지를 클라이언트 콘솔에 띄어주고 클라이언트에게서 받은 메세지가 공백이 아니라면 받은 메세지를 서버 콘솔에 출력해주고 이를 클라이언트 콘솔에도 반환해준다. 클라이언트가 ‘exit’ 문자를 입력 시 감사 메세지를 출력하고 연결 종료한다.
```c
    @Override
    public void run() {
		//버퍼드리더를 통해 바이트 단위로 데이터를 넘기지않고 한 번에 효율적으로 데이터를 넘겨준다.
        try (BufferedReader in = new BufferedReader(
                new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
             PrintWriter out = new PrintWriter(
                     new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true)
        ) {
            out.println("환영합니다! " + clientId +"님 끝내시려면 'Exit' 를 입력해주세요.");
            String line;
            while ((line = in.readLine()) != null) {
                System.out.println("[서버] 클라이언트에게 온 메세지 " + clientId + ": " + line);
                
                //equalsIgnoreCase() 메소드는 대소문자 상관없이 같은 문자인지 확인
                //trim() 메소드를 통해 클라이언트가 입력한 문자열 앞, 뒤 공백을 제거
                if ("exit".equalsIgnoreCase(line.trim())) {
                    out.println("감사합니다. " + clientId + "님");
                    break;
                }
                out.println("클라이언트가 보낸 메세지 " + clientId + ": " + line);
            }
        } catch (IOException e) {
            System.out.println("[서버] 클라이언트 " + clientId + "IO error: " + e.getMessage() );
        } finally {
            try {
                socket.close();} catch (IOException ignored) {} //IOException ignored -> 무시
            System.out.println("[서버] 클라이언트 " + clientId + " 연결 종료");;
            }
        }
```

### 클라이언트 서버
- 데이터의 입출력을 어떻게 할지 설정해주고 한글 데이터가 깨지지 않게 UTF_8을 설정해준다. 서버와 연결되었을때 연결 메세지를 출력하고 서버에서 환영 메세지 데이터기 왔다면 그대로 출력해준다. 클라이언트가 메세지 작성 시 서버 콘솔에 출력해주고 작성한 메세지를 서버에게 반환받아 출력해준다. 반환 받은 데이터가 없다면 연결 종료 메세지를 출력해준다. ‘exit’ 문자 작성시 종료한다.
```c
    public static void main(String[] args) {

        String host = "127.0.0.1";
        int port = 20000;

        try (Socket socket = new Socket(host, port);
				//버퍼드리더로 읽기 성능 향상
                BufferedReader in = new BufferedReader(
                new InputStreamReader(socket.getInputStream(), StandardCharsets.UTF_8));
             PrintWriter out = new PrintWriter(
                     new OutputStreamWriter(socket.getOutputStream(), StandardCharsets.UTF_8), true);
             BufferedReader keyboard = new BufferedReader(
                     new InputStreamReader(System.in, StandardCharsets.UTF_8))
        ) {
            System.out.println("[클라이언트] 연결 " + host + ":" + port);

            String greet = in.readLine();

            if (greet != null) {
                System.out.println(greet);
            }

            String msg;
            while (true) {
                System.out.print("[클라이언트]: ");
                msg = keyboard.readLine();
                if (msg == null) break;
                out.println(msg);
                String reply = in.readLine();
                if (reply == null) {
                    System.out.println("[클라이언트] 서버가 연결을 종료했습니다.");
                    break;
                }
                System.out.println(reply);
                if ("exit".equalsIgnoreCase(msg.trim())) break;
            }
            System.out.println("[클라이언트] 감사합니다.");
        } catch (IOException e) {
            System.out.println("[클라이언트] 에러: " + e.getMessage());
        }
    }
```
