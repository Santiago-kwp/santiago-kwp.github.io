### 입력 스트림과 출력 스트림
프로그램을 기준으로 데이터가 들어오면 입력 스트림, 데이터가 나가면 출력 스트림
입력 스트림과 출력 스트림 모두 존재해야 데이터 교환 가능



### 입출력 스트림
바이트 스트림의 최상위 클래스는 InputStream/OutputStream
문자 입출력 스트림의 최상위 클래스는 Reader/Writer

복합적인 데이터(이미지 및 영상) FileInputStream/FileOutputStream 로 처리
문자 데이터 FileReader/FileWriter 로 처리



### 보조 스트림
다른 스트림과 연결되어 여러 편리한 기능을 제공해주는 스트림 (스트림에 필터를 달았다고 생각)

보조스트림 변수 = new 보조스트림(입출력스트림);


### 객체 스트림
직렬화: 메모리에 생성된 객체를 파일 또는 네트워크로 출력하기 위해 필드값을 일려로 늘어선 바이트로 변경하는 것
역직렬화: 직렬화된 바이트를 객체의 필드값으로 복원하는 것
