### MVC 패턴이란?
- 애플리케이션을 세 가지 역할로 나누어 개발하는 디자인 패턴으로 코드의 재사용과 유지보수를 쉽게 만들어 줌

#### Model
- 역할: 데이터와 비즈니스 로직을 담당
- 하는 일: DB와 통신하여 데이터를 가져오거나, 저장하고, 수정, 삭제


#### View
- 역할: 사용자에게 보여지는 화면(UI)을 담당
- 하는 일: 컨트롤러로부터 받은 모델의 데이터를 화면에 그리거나 사용자의 입력을 받아 컨트롤러에 전달

  
#### Controller
- 역할: 모델과 뷰 사이의 상호작용을 제어하는 중재자
- 하는 일: 사용자의 요청(Request)을 받아, 어떤 모델을 사용할지, 어떤 뷰를 보여줄지 결정하고 지시합니다.


### CRUD란?
- 대부분의 컴퓨터 소프트웨어가 가지는 기본적인 데이터 처리 기능 네 가지를 묶어 부르는 말

#### C(create)
- 데이터의 생성(DB의 INSERT)

#### R(read)
- 데이터의 조회(DB의 SELECT)

#### U(update)
- 데이터의 수정(DB의 UPDATE)

#### D(delete)
- 데이터의 삭제(DB의 DELETE)


### 데이터의 흐름 방향
View → Controller → Model(Service, DAO) → DB → Model → Controller → View
